# React Developer Portfolio

A minimalist, responsive personal portfolio built with React, Vite, and Tailwind CSS. Showcases my frontend development skills, personal projects, technology stack, learning journey, and contact information.

## Tech Stack

- React
- JavaScript (ES6+)
- Tailwind CSS
- Vite
- Lucide React

## Features

- Responsive navigation
- Animated background and scrolling technology strip
- About section and personal introduction
- Project showcase with image previews
- Technology stack with interactive hover effects
- Learning journey section
- Contact links and responsive footer

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
